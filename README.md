This project is written in C++ coding language.

There are two parts of single project.

First part is Ticket Booking System, For users.
It is basically a PVR Ticket Booking System.
To run the program, you need to open PVRticket.exe in your pc or laptop. Or, if you want to see coding, you can open PVRTicket.cpp in vs code.
Now enter your details like name, age, movie you want to watch and seat you want to prefer.
Based on your details, it will Show Your Ticket Number and also save your details side by side in tickets.txt file.
Remember: you can not add wrong details, as it will not accept, and you will need to add it again.
-------------------------------------------------
Second part is Ticket Managing System, For Ticket Managet

To run the program, you need to open TicketManager.exe in your pc or laptop. Or, if you want to see coding, you can open TicketManager.cpp in vs code.
Here You can Check all the previous ticket bookings, and also search them by customer name/ticket number.
